**aimarket-widget** es la UI embebible para el catálogo y la invocación de capabilities del Hub. Marcas e identificadores de API no se traducen.

## Inicio rápido

Clone el repo del satélite, siga Quick start en el [README inglés](../README.md) y alinee términos con el glosario.

```bash
git clone https://github.com/alexar76/aimarket-widget.git
cd aimarket-widget
# затем — команды из English README → Quick start
```
